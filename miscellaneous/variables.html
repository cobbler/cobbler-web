e2e/item-configs/index.ts

ITEM_CONFIGS_BY_TYPE
Type : Record<string, ItemConfig>
Default value : Object.fromEntries( STANDARD_ITEM_CONFIGS.map((config) => [config.type, config]), )
STANDARD_ITEM_CONFIGS
Type : ItemConfig[]
Default value : [ distroConfig, profileConfig, systemConfig, repositoryConfig, imageConfig, managementClassConfig, packageConfig, fileConfig, menuConfig, ]

"Standard" item types: all follow the identical new_/modify_/save_/remove_/ get__handle XML-RPC surface and the identical dialog-create / isEditMode-edit UI pattern. Template, Snippet (file-content API, no Item object) and NetworkInterface (sub-resource of System, modified via modify_system) are deliberately excluded — they get their own dedicated specs instead of this generic, config-driven one.
